IP Tracker

ipx() {
  export ipx="$1"
  if grep -q '^export ipx=' ~/.bashrc; then
    sed -i "s/^export ipx=.*/export ipx=$1/" ~/.bashrc
    else
      echo "export ipx=$1" >> ~/.bashrc
      fi
      echo "[+] ipx set to $ipx"
}

Cheat sheet

Ping sweep:      nmap -sn <subnet>
Fast scan:       nmap -T4 -F <target>
Full TCP:        nmap -p- -T4 -Pn <target>
UDP (quick):     sudo nmap -F -sU --top-ports 100 <target>
Firewall check:  nmap -sA <target>   (compare ACK vs SYN)
Firewall bypass: -f  --source-port 53
If scan hangs:   --min-rate 1000 --max-retries 1

Privilege Escalation

First run linpeas / winpeas / linenum / exploit-suggester / watson / sharpup.
Set up file transfer, pull output back to your attack box, and read it carefully.

sudo -l          # GTFOBins

# Look for world-writable files (e.g. /var/www/html or /home/*)
# Open the file and add a malicious command (new admin user or root shell)

# Cron job running as root → is the target directory writable?

# Path hijacking
# Modify PATH or write to a directory that appears earlier in PATH
# System searches PATH from left to right

# Token impersonation
# User / Group / Others
# SUID: x becomes s — anyone can execute with the file owner’s privileges
find / -perm -4000 2>/dev/null

We are looking for:

  • Can I run anything as root?
  • Does a binary execute as root?
  • Can a binary bypass normal permissions?
  • Does root execute something I control?
  • Can I modify trusted files?
  • Can I replace what root loads?
  • Is the kernel vulnerable?
  • Did someone leave passwords, SSH keys, or tokens?
  • Can I log into another host?
  • Same password elsewhere?
  • Config files / database / application credentials
  • Mounted NFS / Samba shares
  • Trust relationships
  • Domain access / Kerberos / LDAP
  • Can I escape a container?
  • Can I become root / another user / access another host?
  • Can I obtain credentials?
  • Can I abuse something that already runs with higher privileges?

Common False Positives

  • Failed logon → wrong password typed
  • Account lockout → forgot password across devices
  • PowerShell → IT admin activity
  • cmd → batch files, installers, software updates
  • rundll32 → Windows, Control Panel, printers
  • regsvr32 → software install / updates
  • msiexec → software deployment
  • New service installed → legitimate installation
  • WMI → monitoring software
  • Remote logon type → helpdesk, admins, backup software
  • SMB → file shares, printers, domain traffic
  • DNS spike → browser startup, Windows Update, AV update
  • Encoded PowerShell → management tools, Defender, Exchange, SCCM
  • Network connection → updater, AV engine, telemetry

Does it fit normal business activity?

Indicators of Compromise

  • Multiple failed logins from the same IP
  • Successful login after many failures
  • New domain admin account created
  • User added to administrators
  • Unexpected PowerShell or cmd activity
  • Connections to known C2 IPs
  • Outbound data transfers
  • New scheduled tasks, services, or startup entries
  • AV disabled
  • Web server anomalies
  • Copy of an .exe in a writable directory
