Fields in Forensics

by j4ck13

Digital forensics is not one job. It is a family of specialities that share the same rules: preserve the evidence, document everything, and prove what you found.

Disk forensics

Examining storage devices and their file systems: deleted files, timestamps, user activity and artefacts left by the operating system.

Memory forensics

Analysing a RAM capture to see what was running at a moment in time: processes, network connections, injected code and keys that never touch the disk.

Network forensics

Reconstructing activity from packet captures, flow data and logs. It answers who talked to whom, when, and how much data moved.

Mobile forensics

Recovering messages, location data, app data and call records from phones and tablets, where encryption and constant software changes make the work harder.

Cloud forensics

Investigating in environments you do not physically control. Evidence lives in provider logs, identity systems and snapshots, so access and retention matter.

Malware analysis and incident response

Closely related roles. Incident responders contain and investigate live attacks, while malware analysts study what a sample does. Together with forensics they are often called DFIR.

The rules that apply to every field

  • Preserve: work on copies and use write blockers where you can.
  • Verify: hash evidence so you can show it has not changed.
  • Track: keep a chain of custody for who handled what, and when.
  • Document: record every step so someone else could repeat it.
